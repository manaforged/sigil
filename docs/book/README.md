# The Sigil Book

The guide to building native Rust UIs with Sigil — from first window to
production patterns.

- [00 — Quickstart](00-quickstart.md): install, first app, the four
  moving parts.
- [01 — The reactive model](01-reactive-model.md): signals, derived,
  effects, batching, events, tasks.
- [02 — Styling](02-styling.md): utility classes, the cascade, themes
  and tokens, interaction states, hot reload.
- [03 — The widget catalog](03-widgets.md): every widget, its
  highlights, and the honest interaction-state table.
- [04 — Testing](04-testing.md): headless harnesses, event routing,
  goldens.

Companion material: the `examples/` directory (19 compile-checked apps,
each with a `FRICTION.md` log of the authoring experience that shaped
this API), the rustdoc on `sigil-ui`, and `docs/decisions/` for the
design rationale.
