# sigil-fonts

The fonts [Sigil](https://github.com/manaforged/sigil) draws with by default. `sigil-ui` pulls this crate in with its `scene` feature, so most apps never depend on it directly.

| Font | Use | License |
| --- | --- | --- |
| Fira Sans Regular, Medium, SemiBold | Interface text | SIL Open Font License 1.1 |
| Cascadia Mono | Monospace text | SIL Open Font License 1.1 |
| Noto Color Emoji (subset) | Color emoji | SIL Open Font License 1.1 |
| Sigil Symbols (DejaVu Sans subset) | Arrows, keys, shapes, and other symbols | Bitstream Vera and Arev licenses |

`fonts/NOTICE.md` lists the copyright holders and how each subset was made. The license texts are `fonts/LICENSE-OFL.txt` and `fonts/LICENSE-DejaVu.txt`. Each font keeps its own license; Sigil's MIT license does not extend to it.
